  IMPORTANT:
  Please iterate through every profile you've added and choose an platform (this is now a required field).
  If you don't have any platforms available, then open the application "Codetables" and add Entrys to "iM - Images / Symbols" and "pF - Platforms".


  IMPROVEMENTS
  ____________

  * -
  

  NEW FEATURES
  ____________

  * Session Cleanup lets you clean out sessions, that took less than a specified amount of time.
    This is useful for cleaning out sessions that were created by accident or by testing.

  * Added a new option to override the global blackout setting (side monitors while monitoring) on profile layer.


  BUG FIXES
  _________

  * Fixed a bug, where Timestamps were not being updated correctly when data was saved.

  * Fixed a bug regarding detection of currently running games, where the application was not able 
	to detect some games that were running in the background.

  * Fixed a bug regarding the automatic switching of the selected application (from menu)
